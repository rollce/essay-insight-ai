# Essay Insight AI

AI-inspired essay analysis web app with transparent scoring and actionable feedback.

## Highlights
- Text analysis endpoint (`POST /api/analyze`) with explainable scoring
- Metrics for readability, structure, coherence, and keyword extraction
- Animated UI designed for admissions-focused portfolio presentation
- Fully English product copy and docs

## Tech Stack
- Next.js 16 (App Router + Route Handlers)
- TypeScript
- Tailwind CSS 4
- Framer Motion

## Local Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm start
```

## Railway Deployment
1. Create and link a Railway project.
2. Railway auto-runs install/build/start steps for this app.
