# Essay Insight AI

Multi-page NLP web application for essay scoring and explainable feedback.

## What is included
- `Overview` page for product framing
- `Analyze` page with live scoring via API
- `History` page with score tracking records
- `Methodology` page with scoring logic and ethics notes

## UI and Architecture
- Ready UI blocks from **Ant Design** (`Menu`, `Card`, `Table`, `Steps`, `Collapse`)
- Motion and transitions with `framer-motion`
- Analysis backend via `/api/analyze`

## Tech Stack
- Next.js 16 + App Router + Route Handlers
- TypeScript
- Tailwind CSS 4
- Ant Design
- Framer Motion

## Routes
- `/`
- `/analyze`
- `/history`
- `/methodology`
- `/api/analyze`

## Run locally
```bash
npm install
npm run dev
```
